# 测试与质量

作者：Jeff.Liu。PDLC方法改编来源与许可见[声明](../../../references/third-party-notices.md)。

## 测试地基与TDD

先从项目声明和runner发现真实测试入口，兼顾内联测试，不靠文件名判定“无测试”。读取已有`docs/00_standards/test-commands.yml`及测试/覆盖率配置；首次建立或refresh只登记真实核验过的命令、目录、依赖环境和覆盖范围。命令失效应报告配置漂移，正常失败则记录未通过；空命令、缺工具、超时或缺依赖都是未验证。替换runner后验证同等范围，不能删检查、放空命令或降阈值让门禁变绿。

复用既有测试目录和框架；没有时提出最小方案，新增依赖遵守授权。不默认安装hooks或改CI，不为运行测试启动桌面应用。已授权修改配置时保留差异和原因。

Converge负责先测试、确认因目标行为缺失而红灯，再实现绿灯与必要回归。编译失败、依赖不可用、收集不到测试不证明TDD红灯。正常、边界、异常与非法参数均考虑；已有缺陷先复现，重构前后保持行为不变。不能用测试数、覆盖率或一次绿灯替代断言语义和FR/AC核对。

## E2E与质量门禁

从当前PRD/AC核对关键业务流和优先级，将每条流映射到实际测试选择器；无优先级或无法判断覆盖范围时标出，不将空集当全部覆盖。使用项目现有无界面E2E工具，在隔离环境运行；记录源码、构建、环境、范围、命令、退出码与逐测试结果。仅生成用例则报告未执行。缺映射、测试消失、失败、跳过、未执行和孤儿映射分别列出，不能只看汇总退出0。

质量报告引用本次实际lint/测试/覆盖率/E2E证据，对照项目已确认目标；PRD→关键流→测试→本次结果逐层对账。阈值与命令强制线矛盾要指出，不能取较低值通过。安全、性能等专项没有执行时单列。Markdown或项目既有格式为真源，需要HTML时同数据生成可离线视图并核对关键数字，不把无法判定显示为绿色。

[原始测试证据工具](../../project-docs-lifecycle/references/engineering-evidence.md)支持Converge已有格式及支持的runner；其他E2E/安全/性能格式保留原报告和来源，尚无通用解析器，不能伪装成受支持回执。自动测试证据不等于人工AC、UAT或发布批准。

## lint与安全

lint check先发现并使用现有工具，保存命令和问题；fix只修授权范围、审查diff并复跑；setup先核对既有规则再补配置，不更换整套格式规范。无法安全自动修复的项交接；检查失败与工具不可运行分开。

安全审计先运行已有依赖漏洞与密钥扫描工具，记录版本、退出码、范围与原报告，再检查鉴权/越权、注入/XSS、敏感数据、配置和外部调用。扫描缺失或漏洞库过期要说明；静态阅读只能称人工/模型审阅。报告含证据位置、影响、严重度、修复与验证办法，密钥脱敏。修复走Converge测试先行，不自动升级全部依赖或改变鉴权设计。

## 性能

先约定可重复指标与测量命令，保存数据量、并发、机器和版本；同一命令至少3次取中位数作为基线，优先依profile/慢查询等定位瓶颈。一次只改变一个因素，先保持行为回归，再用同环境同命令复测；没有实测收益的优化不保留。无测量环境时只交分析和方案，代码推测注明假设，不给编造的提升百分比。实际压测、数据库查询与外部调用遵循用户现有授权和环境边界。
