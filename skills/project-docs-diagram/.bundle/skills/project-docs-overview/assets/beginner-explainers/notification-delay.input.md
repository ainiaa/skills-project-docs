# 通知延迟解释：合成业务材料

读者：处理咨询的客服。请求：用零基础图解页面解释订单已受理但用户反馈没收到通知，说明现在能知道什么、还需要查什么。

- 业务设计将订单受理与通知发送分为两个步骤；用户收到通知还依赖通知实际送达。
- 当前订单记录为“已受理”，通知记录为“待发送”。
- 用户反馈没有收到通知。没有发送日志或送达回执，尚不能核实通知服务的实际执行和送达情况。
- 通知异常不会自动取消已受理订单。
- 可以建议核对发送任务、发送日志和送达回执，但不能断言网络故障、服务宕机或已经重发成功。
- 没有获准执行重发或修改订单，本次仅解释及提出排查方向。

所有状态都是合成材料，不代表访问过真实服务。
