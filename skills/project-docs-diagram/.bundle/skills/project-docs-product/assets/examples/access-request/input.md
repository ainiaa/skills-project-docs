# 资源权限申请：模拟验收输入

作者：Jeff.Liu

本次授权来自易用性复核后的优化任务：暂停真人试点，完成一个不同于退款的模拟完整原型。沿用原 access-request 的业务范围，新增 HTML 与浏览器旅程交付；不修改原来仅交付 PRD 的冻结样本或它的评测结论。

员工提交资源标识和申请理由，去除首尾空白后非空，不新增长度上限。直属主管接收同一申请并批准或填写原因拒绝；员工只能撤回自己的待审批申请。批准后交资源管理员，执行受理只进入开通中，外部成功才已开通；失败显示原因并允许重试。重复审批、执行、成功通知不产生额外有效操作，角色与状态检查独立于按钮。列表、详情、待办及记录共享同一对象。

本次只模拟一个申请人、其直属主管、资源管理员和其他员工；可注入创建/操作请求失败及外部成功/失败，以验证恢复。没有真实登录、网络、存储或生产授权。真实身份、外部接口、超时、旧尝试迟到或冲突结果仍未决，不在原型中擅定；普通顺序结果和同次重复结果可以验证。

交付一份正式 PRD、可重置的独立 HTML 和自有旅程测试；包括正常、拒绝、撤回、失败重试、重复/非法操作，以及窄屏和键盘。不是新上下文盲测，不以此证明通用模型生成成功率或真实交接效果。仍不提交、不发布。
