# 维修查询技术设计 sim-1

作者：Jeff.Liu。输入：[PRD](prd.md)，身份 SIM-REPAIR-001。仅实现模拟只读 API，无数据库、外部网络或新依赖。

标准库 Python：query(authorization, repair_id, available) 校验固定合成身份、单号、源可用性及记录归属，返回 HTTP 状态和 JSON。HTTP 层仅 GET /repairs/{id}、GET /health，将请求头传到共享 query，查询字符串不参与认证。错误响应只有 error，无维修明细。状态映射：200 正常；400 非法单号；401 无效身份；403 越权；404 未知路由或合法但不存在的工单；503 数据源不可用。健康检查正常为200，源不可用为503；响应包含当前 app.py 的 SHA-256 便于核对部署字节。

边界：R- 加三位 ASCII 数字；维修数据为只读固定样本，查询返回新的字段字典。合成身份 demo-alice/demo-bob 不是生产密钥，不提供真实认证安全保证。服务固定监听127.0.0.1，动态端口；不接受外部网卡参数。无前端、CORS或写接口，不记录请求认证头。

先写 test_app.py 并保留失败输出，再实现 app.py。构建为已测 app.py 单文件，摘要标识制品；独立发布目录复制同一字节并校验 SHA-256，在新进程启动 HTTP 服务，执行覆盖 AC 的真实请求。所有 HTTP 请求固定回环地址、不使用系统代理，设置超时；运行器在成功、失败和超时后均关闭子进程。

发布计划：模拟产品/业务负责人确认 sim-1 与 AC，技术检查通过后，仅对本地隔离范围执行用户已授权的发布。先健康和业务冒烟，再注入源不可用配置，观察健康/业务503；停止故障进程，从已测包重新启动正常配置，核对摘要及原始业务结果。此为只读恢复，无数据迁移或外部副作用；不声称已验证真实系统补偿。

交接：input.md→prd.md→design.md→test_app.py/app.py→构建摘要→测试日志→HTTP回执→故障与恢复→lifecycle-record.json；业务确认与批准标模拟，技术动作记录实际命令、时间、结果和摘要。演练后停止临时服务，保留可重跑代码和证据包。真实试点应由业务指定询问次数基线、观察期和Owner；本次效果保持待观察。
