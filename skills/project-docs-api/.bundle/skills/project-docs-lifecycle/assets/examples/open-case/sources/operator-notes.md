# 可获得的现状资料（模拟）

运营通过团队现有命令运行 python3 legacy_export.py --session S1 --input registrations.csv，取得场次人数，再把结果交给现场组织者。员工无需直接使用此命令。本次可实际复演这条既有命令链；没有外部账号或真实通知渠道。

两个渠道按报名记录导出后合并，每条记录有 record_id、employee_id、session_id、status、source。员工编号在样本中为合成值。取消、重复、跨场次及缺失字段分别应如何计数，还需要向模拟业务角色确认。原始表用于核查，不应擅自覆盖。

现有脚本内容可直接检查。没有提供其他系统、配置开关或管理后台。资料不足处保持未知，不推断现实公司也没有这些能力。真实频次、影响人数、人工耗时和业务价值均无实测数据。
