# 按读者与用途组织交付

先按任务与交付物选择专用 Skill，再确定读者的知识缺口和阅读目的。读者适配改变表达与组织，不改变已承诺范围、事实、规则真源、授权或验收标准；直接调用子 Skill 也遵循此约定。

## 确定本次需要解释什么

- 优先使用用户明确指定的读者、已有知识、用途和格式；复用当前任务已知信息，不重复提问。
- 分别判断对当前业务和技术的熟悉程度。职位、年资或“专家”称呼只是线索，不能推定两方面都熟悉；ELI5 只适用于需要建立基础理解的部分。
- 用途决定重点：理解、操作、评审、决策、实施或排障。信息缺失且会实质改变交付时，合并询问最关键的读者/用途问题；否则采用与任务相符的假设并简短说明，先交付可审阅结果。
- 不要求读者问卷、固定等级、配置文件或新增状态字段。用户明确的结构和格式优先，既有正式模板与生成契约继续有效。

| 读者与用途 | 优先呈现 | 不应自动推定 |
| --- | --- | --- |
| 主题新手建立理解 | 术语就地解释、具体例子、主要关系与边界 | 简化允许删掉关键条件、异常或风险 |
| 操作人员完成任务 | 入口、步骤、成功信号、异常出口 | 所有人需要源码或架构细节 |
| 领域专家评审 | 定义与口径、条件组合、边界反例、证据和未决项 | 专家已同意规则，或已经熟悉实现 |
| 技术专家但业务陌生 | 先补业务对象与规则，再给任务所需技术信息 | 技术熟练等于业务熟悉，或没有源码也能推断实现 |
| 熟悉领域的研发/运维实施排障 | 契约、状态、失败恢复、验证方式及可核对证据 | 可省略前提，或必须罗列无关实现细节 |
| 决策者比较方案 | 影响、备选、收益与代价、依赖条件、需要决定什么 | 摘要可以隐藏阻塞或替其作业务决定 |

专家也可能只需要短结论；新手也可能需要完整操作说明。长度由任务决定，不能用字数或术语密度代替适配质量。

## 保持同一事实和业务边界

- 数字、单位、状态、规则例外、参数、权限、未决项及批准/上线状态不能随读者改变。精简时保留影响结论的条件，并关联所需证据。
- 多读者优先使用共同结论和同一主干，再按任务分层放实施、运维或证据细节。同一需求的正式 PRD 保持唯一主文及身份、版本和有效 FR/AC；读者摘要或视图引用它，不另立相互竞争的规格，不把不同需求强行合并。影响业务判断的规则不能只藏在附录。
- 面向专家可以提出评审问题和有依据的建议，但材料未给出的规则、根因、技术实现或运行效果仍标为未确认；不能因“专家视角”补造。
- 读者熟练程度不改变权限、审批、测试门禁或原型的既定业务行为。跨角色交付只携带获授权资料，缺少访问权时注明证据缺口。

## 按交付物落实

| 交付物 | 适配方式与保留项 |
| --- | --- |
| Overview 文档与 explainer | 新手侧重建立理解；专家侧重定义、边界、依据和取舍。HTML 是交付形式，不等于 ELI5；沿用已选模板或页面契约 |
| Product PRD、评审与原型 | 按用途调整讲解顺序和辅助说明，保留主文、编号、规则及完整用户任务；不因读者层次改业务约束或扩展本期需求 |
| API 文档 | 生成原文、字段、必填、枚举、示例及请求的逐字接口片段保持原契约；业务解读放交付回复或按需独立说明，关联同一接口，不重写机器产物 |
| Diagram | 保留指定记法、必需标签、关系和证据；新手可补图例或总览，专家可按需展开细节，不靠删掉关系简化图 |
| Lifecycle 交接 | 在已有目标/范围说明中携带接收读者及用途，保留同一身份、版本、证据、缺口与下一动作；可读摘要不替代就绪判断或人工批准 |

## 交付前核对

确认读者能完成本次目的：新手能复述或操作，专家能核对关键条件、反例与证据，决策者能看到选择与后果。比较各读者视图时检查事实、状态及未决是否一致；涉及生成原文和正式规格时核对未被改写或另立版本。

示例使用[同一份合成报名材料](../skills/project-docs-overview/assets/beginner-explainers/registration-rule.input.md)：[首次报名者说明](../skills/project-docs-overview/assets/beginner-explainers/registration-rule.archify.md)先解释确认与候补，[业务专家评审页](../skills/project-docs-overview/assets/beginner-explainers/registration-rule-expert.archify.md)先列口径和待决边界；两者的四组判断结果保持一致。这些是适配示例，不是新的正式 PRD。

资源检查、固定案例和内容复核分别记录；没有独立会话测试或真实读者试读时，不声称所有读者都能稳定理解。
