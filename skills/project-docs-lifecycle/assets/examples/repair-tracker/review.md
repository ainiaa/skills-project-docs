# 产研交接走读 sim-1

作者：Jeff.Liu。实际执行者：本次模型会话；非独立评审者、非真实业务批准。

业务阅读问题：员工能否知道接下来做什么？PRD FR-01 规定 R-100 返回当前状态和下一步；AC-04/05 给出核对单号的恢复动作，FR-02 让故障时由维护角色先恢复再重查。没有用户界面，本轮只验证接口任务，不宣称员工实际可用性或减少问询。

研发阅读问题：身份与数据从哪里来，查询会不会写工单？PRD 的数据约束及 design.md 明确使用固定合成身份/数据，查询只读；真实身份和数据接入未实现。调用路径为 Header→共享query→格式/可用性/归属校验→公开字段响应，查询参数不能代替身份。

测试阅读问题：正常、越权、边界和源异常的预期能否确定？AC-01 至 AC-07 均给出输入及结果，test_app.py 一一对应；隔离 HTTP 再覆盖 bob 带 owner=alice 参数、健康状态503和同构建恢复，不能仅用纯函数测试证明部署成功。

保留对照：原始员工诉求对应 FR-01/AC-01；行政“不可看他人”对应 AC-02/03；“查询不改状态”对应 AC-07；D1–D4 边界、故障、隔离授权分别在范围、FR-02、设计发布段承接。未引入新账号、数据库、前端或审批平台。真实效果仍待观察。
