# 模拟业务输入 SIM-REPAIR-001 v1

作者：Jeff.Liu。此文件是本次演练创建的虚构业务资料，不代表真实公司事实、调研、员工或批准。

模拟员工原话：“电脑报修后只知道提交成功，不知道修到哪一步，反复找行政问。”模拟行政原话：“只读查询应显示进度和下一步，不能看到别人的工单，也不能因查询失败改掉维修状态。”

本次模拟角色：业务方无 AI，通过纪要输入；产品/研发有 AI，由同一执行会话接续。另一个组织若业务有 AI，可以先提交草稿，确认与访问责任不变。本轮用户授权完整模拟案例和本地隔离执行；模拟业务角色的确认不能转化为生产权限。

模拟业务决定 D1：范围为只读查询接口，不新增报修、修改状态、通知、账号系统或前端；用合成身份和合成内存数据验证行为。D2：只查自己的维修单，其他人的工单返回无明细的拒绝结果；不存在和格式不合法分别说明。D3：数据源故障明确提示稍后重试，本次不改原工单。D4：先在本机回环地址和动态端口隔离上线，业务 UAT 和发布批准仅模拟，真实业务效果待观察。

模拟数据：R-100 归 alice，设备 laptop，状态 repairing，下一步“等待维修完成”；R-200 归 bob，状态 ready，下一步“联系行政领取”；R-999 不存在。无历史系统、旧页面或真实数据迁移。本期无需业务数值计算或新流程平台。
