# 资源权限申请与异步开通

> 产品版本：demo-1
> 文档修订：1
> 状态：草稿

## 业务摘要与阅读导航

员工申请，直属主管审批，资源管理员执行，外部结果确认是否开通；批准不等于已开通。待审批可撤回，拒绝和撤回为终态，执行失败可重试。本稿验证另一类完整模拟流程，不代表真实业务已确认。

| 读者 | 本次可判断的内容 | 依据 |
|---|---|---|
| 业务 | 申请、审批、执行与结果责任是否清楚；超时和冲突处置尚待决定 | FR-001 至 FR-006、Q-001 |
| 研发 | 同一申请贯穿角色交接，真实身份和外部契约仍待核实 | 流程覆盖表、Q-001/002 |
| 测试 | 可准备正常、拒绝、撤回、失败恢复、重复和非法操作；本稿附模拟交互检查 | AC-001 至 AC-015、journey.test.mjs |

## 背景、范围与约束

本期覆盖一个模拟申请人及其主管、管理员和其他员工，使用内存数据；刷新或确认重置会清空。提供 [HTML 原型](prototype.html)，无真实后端、身份或外部平台。预期价值是检验生成材料能否表达角色交接，未测量效率收益、性能、真实岗位阅读效果或生产影响。无排期及真实授权。

## 需求与验收

### FR-001 输入与创建

状态：待确认
依据：SRC-001
原型：是

员工在创建弹窗填写资源标识与理由；去首尾空白后非空，不添加长度上限。保存成功生成唯一申请 ID 并进入待审批，输入保存在同一对象；失败不生成申请或主管待办，保留输入。演示采用 JavaScript trim，真实字符口径待 Q-002 核实。

#### AC-001 正常创建

输入两侧空格的资源标识及理由，保存后详情显示裁剪值；主管待办出现同一 ID 和内容。

#### AC-002 必填和长输入

分别为空或全空格不能保存，反馈对应字段；1001个汉字的非空理由可保存，不以额外上限拒绝。

#### AC-003 创建失败与恢复

注入一次创建失败，保留表单值且没有申请/待办；恢复后可以重新提交。取消弹窗不生成申请。

### FR-002 主管审批

状态：待确认
依据：SRC-001
原型：是

主管仅审批待审批申请，批准进待开通，拒绝需非空原因并进已拒绝；禁止自批及其他角色审批。请求失败不得提前成功。演示拒绝原因按 trim 判断，真实口径待核实。

#### AC-004 批准与待办交接

主管批准后移出主管待办，管理员待办出现同一 ID；员工看到待开通，不能显示已开通。

#### AC-005 拒绝及原因

无原因不能拒绝；填写原因后成功拒绝，各处显示相同原因且不进入管理员待办。失败可重试且不提前改变状态。

#### AC-006 非法审批

员工或其他员工绕过按钮调用模拟动作，状态和记录均不变并提示角色受限；合法主管的模拟请求失败也不改变状态。

### FR-003 员工撤回

状态：待确认
依据：SRC-001
原型：是

员工仅可撤回自己的待审批申请，已撤回为终态；批准后不可撤回。按当前对象状态检查旧页面动作，不以旧按钮状态决定结果。

#### AC-007 撤回与旧页面

撤回后主管旧详情再批准失败，仍为已撤回且不产生开通任务。

#### AC-008 非法撤回

待开通及后续状态不能撤回；其他员工不能撤回当前申请人的记录。演示顺序执行只验证先后操作，真实并发裁定待 Q-002。

### FR-004 执行与结果恢复

状态：待确认
依据：SRC-001
原型：是

管理员对待开通申请提交执行，受理后开通中；外部成功才已开通，失败为开通失败并显示原因，可从待办重试回开通中。提交/重试失败保持原状态。外部按钮为人工模拟输入，不发送网络请求。

#### AC-009 正常开通

执行受理后保持开通中，等待人工注入成功结果才显示已开通；员工结果跟踪读取相同状态和申请 ID。

#### AC-010 失败与重试

外部失败后有可达的管理员待办入口，详情显示原因；重试受理后重新开通中，成功后已开通。

#### AC-011 受理失败和等待

执行/重试请求失败保持待开通/开通失败，未增加模拟受理次数；外部结果未注入时不自动成功。超时行为未实现，见 Q-001。

### FR-005 角色、状态与重复操作

状态：待确认
依据：SRC-001
原型：是

模拟动作入口独立校验角色和当前状态；重复审批不更改首个有效结果，同次重复执行不重复受理，相同成功结果不重复记为有效操作。合法失败重试可新增一次受理；历史显示有效动作，受理次数仅是本地演示计数，不是外部平台执行证据。

#### AC-012 重复审批和旧状态

批准、拒绝或撤回后再审批，不改状态或有效记录；这里只证明顺序模拟行为，不证明真实并发安全。

#### AC-013 重复执行与通知

开通中再次执行不增加受理次数；已开通收到相同成功通知不增加有效记录，失败后的合法重试增加一次受理。

#### AC-014 非法执行

员工、主管不能执行；管理员对待审批或终态执行，状态不变且模拟受理次数不变。

### FR-006 列表、详情与记录

状态：待确认
依据：SRC-001
原型：是

所有视图共享同一申请对象及历史；我的申请按员工、待办按当前角色/状态筛选，结果跟踪按当前状态同步。其他员工无申请及处理权限；当前主管和管理员可查看本演示对象，真实数据范围待 Q-002 核实。用户可取消创建、返回列表或确认重置，不能隐藏地重置业务状态。

#### AC-015 同对象同步与可重复演示

创建、交接、失败重试、终态均核对同一 ID、内容、状态及记录，退出不丢已有申请；取消重置保持数据，确认重置恢复空列表。窄屏无页面级横向溢出，键盘可创建、取消和撤回。

| 旅程 | 角色及交接 | 入口、步骤与结束结果 | 失败恢复 | FR/AC 与检查 |
|---|---|---|---|---|
| 正常 | 员工→主管→管理员→员工 | 创建→待办审批→执行受理→外部成功→结果跟踪 | 受理失败原状态重试 | FR-001/002/004/006；AC-001/004/009/011/015；journey.test.mjs |
| 拒绝 | 员工→主管→员工 | 待审批→填写原因拒绝→结果可见 | 空原因阻止、请求失败可重试 | FR-002/005；AC-005/006/012 |
| 撤回 | 员工→主管 | 待审批→撤回终态，旧审批不可操作 | 批准后撤回被阻止 | FR-003；AC-007/008 |
| 失败重试 | 管理员→模拟平台 | 开通中→失败→待办重试→成功 | 失败后保留可达入口 | FR-004/005；AC-010/011/013 |
| 输入/非法/重复 | 各模拟角色 | 字段错误可修正，角色或状态非法不改变对象 | 保留输入、反馈原因 | FR-001/005；AC-002/003/006/012/013/014 |
