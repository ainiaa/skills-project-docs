# 产品行为评测

评测真实成品的决定与使用结果，不以关键词、编号或结构通过判定语义优秀。按本次变化选择少量相关样本；不默认重跑全部，也不以有限样本承诺稳定成功率。

评审标准直接引用权威约定：[来源、确认及恢复走读](workflow.md)、[正文、角色阅读及交付](reading-and-change.md)、[完整原型及旅程](prototype.md)。本文只规定取样与证据；不重复维护另一份产品规范。确定性测试保护文件关联、版本与报告契约，内容效果由实际成品复核，不能用固定句子是否出现代替。

## 样本与观察

| 能力 | 输入或扰动 | 检查实际结果 |
|---|---|---|
| 需求保留 | 资料充分时直接整理，局部修改只聚焦多个独立功能中的一个；或删除一个仍有效约定 | 找到遗漏，能定位主文及验收，撤出须有依据；不复制无关功能 |
| 确认边界 | 口径冲突、标注修订旧口径、局部确认、未回复或暂停恢复 | 保留真决定，不重问；不扩大全文批准；只推进独立部分 |
| 混合与异常恢复 | 已有有效结果＋来源故障、一方完整一方缺失、局部冲突、结果不明 | 正确采用优先级与读写集合；从反馈能找到责任/入口/恢复条件，缺口如实保留 |
| 增量与无源码 | 同业务分别提供源码、无代码截图/口述；新产品无基线 | 目标业务规则一致，差异仅在事实证据；不虚构源码、旧页面或后台能力 |
| 精简与计算 | 简单文案变更；另选计算/分摊需求 | 前者短说明与必要验收即可，后者按需给能复算的单位、基数、公式、输出和候选假设 |
| 图文与原型 | 页面状态改变，随后返回其他页面或处理下一组 | 图、规则、页面及验收采用同一对象和影响边界；完整原型才验证共享状态/导航 |
| 确认继承 | 单文件与显式文件对的版本链，规则/AC/来源改变及未冻结引用 | 未变旧记录保留，受影响项重确认；错版、重复、逃逸、隐藏声明不得通过 |

## 如何执行

生成者使用独立上下文，只读本次输入、当前Skill及必要原始资料，不给oracle、预期答案、旧诊断或其他样本成品；无源码例不得搜索真实仓库补资料。只读评审读取实际文件与必要图片，按workflow.md的覆盖核对和结果走读推导，不能把生成者的自述当证据。

保留输入、Skill/所用资源身份、原始成品与实际完成回执；修订后另记版本/哈希，不把控制器改稿或一次定点修订算成另一次独立成功。修复后仅复测受影响样本，仍有缺口就报告未覆盖；不放宽断言或改冻结输入凑通过。技能身份改变后旧结果仅证明旧版本。

真人试读另由实际业务、研发、测试独立复述规则、设计阻塞和验收，记录重复提问及返工；无人参与时保持未验证，不用模型代替岗位批准，不报告未观测的节省比例。当前真人试点暂不开展。

## 复用现有样本与工具

- `scripts/fixtures/product-behavior/cases.json`：下一动作、确认及范围观察；journey/uncovered使用同一业务阶段词典，保存反馈不等于最终业务结果。
- `artifact-cases.json`及`revision-baseline.md`：实际PRD成品、历史影响及未变确认；`multi-input/cases.json`：同业务多资料条件及冲突的独立试验。输入路径相对上述fixtures目录，不改旧样本含义。
- `lean-split/cases.json`：轻量文案、阈值规则及显式主文/追踪拆分的定向成品试验；每次只选本轮受影响样本，另保留输入、两个模板及必要引用的身份，独立复核主文能否读懂、附件有无新增规则、链接及版本是否一致。不冒充旧全量样本门禁通过。
- `product_behavior_eval.py --artifacts <report.json>`检查成品报告、文件身份及冻结输入信号；`PRODUCT_ARTIFACT_REPORT`和`PRODUCT_BEHAVIOR_REPORT`使相应pytest使用真实报告，缺失则明确跳过。信号和哈希不证明语义、模型作者或批准。
- 成品报告每个样本的 `prd` 为 `{path,sha256}`；拆分时显式增加同结构 `tracking`。两文件联合检查版本、资源及冻结信号，追踪也要校验哈希；旧单文件报告继续有效。历史修订仍须满足冻结输入的保留/变更要求，拆分不自动授予确认继承。报告资源必须在其允许目录内，不隐式放宽来源路径。
- PRD结构用`validate_product_doc.py`；完整原型复用`product_bundle.py`、`product_browser.mjs`及退款/资源权限申请示例的自有旅程。PRD插图、某样例旅程与任意新完整原型分别报告，不互相冒充覆盖。

不为普通文档建立打分、状态机或新工具链。报告只列实际样本、次数、发现、修订与剩余缺口；测试、模型复核、浏览器及真人结果分开记录。
