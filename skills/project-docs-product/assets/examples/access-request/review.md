# 权限申请模拟原型验收

作者：Jeff.Liu

对象：demo-1 / 文档修订1。输入见 [input.md](input.md)，正式规则见 [prd.md](prd.md)。

| 检查 | 实际结果与边界 |
|---|---|
| 结构及资源 | validate_product_doc.py 检查 PRD 与 HTML，valid=true；只证明标识、版本和资源关联 |
| 浏览器旅程 | 自有 journey.test.mjs 经 product_browser.mjs 无界面运行，8项通过，0失败/跳过，输入字节绑定 evidence/browser.json |
| 正常交接 | 员工创建、主管待办批准、管理员执行、等待外部结果、员工实际打开结果跟踪，核对同一申请 |
| 失败及边界 | 必填/长输入、同表单创建失败重试、审批/执行/重试请求失败、外部失败恢复及重复/非法状态操作 |
| 多对象与恢复 | 两条申请的拒绝草稿及一次失败控制隔离，返回保留记录，重置需确认，其他员工无任务 |
| 键盘及窄屏 | 键盘创建、取消、撤回与成功后状态焦点；390×844无页面级横向溢出 |
| 视觉 | 实际查看桌面开通中、失败重试及移动端截图，内容和主操作可辨识；不是跨浏览器验证 |
| 独立模型内容复核 | 另一上下文只读审查；发现拒绝草稿串入第二条申请及成功后未移焦，两项均先补失败回归再修复，定向复核通过 |

浏览器输出不随示例分发，执行 README 的命令后生成，可查看 [回执](evidence/browser.json)、[开通中](evidence/access-processing.png)、[失败重试](evidence/access-retry.png)和[移动端](evidence/access-mobile.png)。回执绑定 input.md、prd.md、prototype.html、journey.test.mjs；输入变化后须重验。8项检查覆盖15个AC的已定义模拟路径，未决边界不计为通过。

本例由当前控制器按明确输入编写，不是新上下文盲测，不推导通用生成成功率。真人试读按用户要求暂不开展；生产身份/权限、真实并发和外部幂等、超时/冲突/旧尝试迟到结果、生产影响和联调均未验证。本次角色与计数只存在于本地内存，无网络调用或持久存储。
