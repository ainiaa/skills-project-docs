# UI与视觉设计

作者：Jeff.Liu。PDLC方法改编来源与许可见[声明](../../../references/third-party-notices.md)。

UI资料关联PRD任务和角色，描述页面/导航、输入校验、关键交互及正常/加载/空/错误状态，补权限与边界。原型由Product按需生成可点击HTML，不以线框说明代替用户所需互动。需要视觉系统时使用实际可用的UI/UX或frontend设计能力，记录配色、字体、组件、响应式和无障碍约束；缺少外部设计Skill可按基础设计完成并说明，无需为普通PRD自动安装。

沿同一正式PRD、FR/AC和产品版本维护交互与视觉决定，不生成第二份需求。需要前端组件、接口联调、可访问性实现及测试时交[Engineering设计方法](https://github.com/ainiaa/skills-project-docs/blob/main/skills/project-docs-engineering/references/design.md)，代码修改沿Converge原任务执行。
